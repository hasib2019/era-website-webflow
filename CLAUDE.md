# ERA Infotech CMS

The Webflow "Era" export in `../era-website/` rebuilt on Laravel 12 so the
content can be edited. The design must not change.

**Load the `era-cms` skill before working here.** It carries the rules; this file
is the short version.

## The two rules

1. **`resources/views/site/**` is generated by `php tools/build.php`.** Never
   hand-edit it. Change the export (`../era-website/Pages/*.html`) for markup, or
   a pass in `tools/` for bindings, then rebuild.
2. **Run `php tools/build.php --verify` after any site change.** It must print
   `all pages structurally identical`. Needs `php artisan serve` running.

`resources/views/admin/**` is hand-written — edit it freely.

## Orientation

```
tools/           the conversion pipeline; build.php runs all of it
docs/            full documentation, start at docs/README.md
app/Support/     Content.php + helpers.php — cms(), setting(), cms_menu()
resources/views/site/    GENERATED
resources/views/admin/   hand-written dashboard
```
